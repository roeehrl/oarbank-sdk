Oarbank spreads batch jobs across the computers you already own: Macs, Linux machines and Windows PCs, mixed in one
fleet. A coordinator plans the work and an agent on every node runs it, while host protection keeps each computer
usable for the people who use it. What the jobs compute is defined by **modules**, built with the open-source module
SDK (Apache-2.0), which talk to Oarbank's [source-available core](https://github.com/roeehrl/oarbank) only through the versioned public contracts
documented here.

Oarbank is not released yet: installers and downloads arrive with the first public release. Its source is public:
the core is at [roeehrl/oarbank](https://github.com/roeehrl/oarbank) and the module SDK at [roeehrl/oarbank-sdk](https://github.com/roeehrl/oarbank-sdk).
You can [install the SDK from source](/oarbank/get-started#install-the-module-sdk), read how Oarbank works and build
modules today.

## Platforms

Nodes run on these platforms. The coordinator runs on macOS or Linux.

| | Versions | Architectures |
|---|---|---|
| macOS | 15 or later | Apple silicon |
| Linux | systemd, Linux 6.2 or later | x86_64, arm64 |
| Windows | 10 version 1809 or later, 11 | x64, ARM64 |

A module declares the platforms its runner supports as tokens: `darwin-arm64`, `linux-amd64`, `linux-arm64`,
`windows-amd64` and `windows-arm64`. What each computer needs is in
[Requirements](/oarbank/operate/requirements); the token rules, portable paths and per-platform declarations are in
[Platforms](/oarbank/spec/platforms).
